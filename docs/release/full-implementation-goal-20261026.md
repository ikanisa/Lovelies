- Stable operation keys, immutable allocated IDs and atomic bounded event manifests, with lookup returning the original accepted plan after a lost reply or PostgreSQL rollback. A retry must not allocate another deletion request or silently change scope.

- A shared transaction gate covering ordinary requests, direct auth/device/session controls, maintenance and internal jobs. Recheck the current generation after awaited Storage/inference/provider work and before releasing bytes, access or external dispatch; stale isolates remain fenced.
- Ordered, exact-episode replay. Distinguish deletion request, independently reviewed rejection/approval and completed erasure. Respect newer consent/profile/device/guardian/adult authority and block→end→new-block episodes. Replay never revives old sharing grants.
